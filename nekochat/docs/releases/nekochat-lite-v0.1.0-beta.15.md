## 本版更新

- 預設啟用自動更新；啟動後及每小時檢查新版，背景下載並核對 SHA-256。可在設定關閉，關閉後會取消等待中的自動重啟。
- 新版下載完成後顯示 5 秒重啟提示；聊天輸入框有草稿或正在組字時會等待，點擊氣泡可立即要求更新。
- 手動更新也改用安裝器接力：主程式完成草稿存檔及資料服務關閉後，才啟動安裝器等待舊行程退出、替換檔案並重新啟動。存稿失敗時保留目前程式，不交接；自動更新等候逾時也不會強制終止舊行程。
- 已有符合條件的同網段防火牆規則時，更新會略過重複的管理員授權；首次安裝或規則缺失時仍可能要求授權。
- 更新安裝交易保留既有設定與資料，安裝交易或啟動呼叫失敗時嘗試還原並重新啟動舊版。此保護不代表能偵測新版啟動後的所有異常。
- 取消更新提示或安裝器啟動失敗後，恢復排隊中的聊天未讀氣泡，重複清理提示不會吃掉已恢復的通知。

## 升級注意

- 從 beta.14 或更舊版本升級，請先下載並執行本版 Setup。該版安裝器可以協助關閉同 Session 的舊版；建議先完成傳送、儲存工作並離開舊版。
- 本版起可使用上述自動更新流程。更新目標是目前使用者的安裝版位置；免安裝版要求更新時也會啟動 Setup，後續使用安裝版。
- 自動更新需要連線 GitHub；教室聊天本身仍使用內網。資料庫沿用 beta.14 的格式。

## 自動化驗證範圍

GitHub Windows runner 建置安裝版與免安裝版，執行既有 WPF、通訊、下載取消、安裝交易與防火牆驗證，並新增原生更新交接測試：實際草稿存稿失敗不啟動安裝器、成功存稿先於交接、安裝器啟動失敗恢復主程式、更新通知清理可重複執行。PID 等待回歸測試確認逾時不終止舊程式。CI 使用隔離 profile、loopback 與合成資料。
