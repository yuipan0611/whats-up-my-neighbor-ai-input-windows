# NekoChat Lite 0.1.0-beta.6：Enter 傳送、自動網路設定與桌面散步

## 下載與安裝

下載 `NekoChat-Setup-win-x64.exe`，先從舊貓咪右鍵選「離開」，再按「安裝並啟動」。兩台電腦都請更新至 beta.6。

安裝時會出現一次 Windows 管理員授權，請選「是」；若電腦要求管理員帳密，需由有權限的人員完成。完成後 App 以原本使用者權限啟動，日常聊天不需要管理員權限。

## 本次修改

- **Enter 直接傳送**；**Shift＋Enter 換行**。修正多行輸入框先吃掉 Enter，導致舊版送出事件沒有收到的問題。
- 中文輸入法組字／選字確認不當作送出；按住 Enter 不連續重送。輸入框附近顯示操作提示。
- **Setup 自動設定內網收訊權限**：精確綁定安裝後的 NekoChat 程式，只允許同網段連入 TCP 8768，套用私人及公用網路。
- 處理舊版 Windows 權限提示產生、且精確對應此程式路徑的預設 TCP 封鎖規則，避免「自己傳得出、別人回傳失敗」。保留其他 App、UDP、自訂管理規則及網域設定。
- 重複安裝不重複新增規則。若遇到自訂封鎖或管理政策，顯示網路設定未完成並復原本次變更。
- 取消管理員授權時，保留已安裝 App，提供重試網路設定或明確略過的選項。略過後可能無法收到同學訊息。
- **修正 Windows 貓咪一直待在原地**：App 的自動散步不再被 Windows「視窗動畫」設定意外停用。內建花色預設開啟自動散步，右鍵選單「🐾 自動散步」可暫停／恢復，並記住選擇；不更動 Windows 的動畫設定。
- 走到螢幕左右邊界時轉向；顯示訊息氣泡、開啟選單或拖曳時暫停，避免妨礙閱讀及操作。自訂靜態圖片維持原本行為。
- 保留純文字 IP 直連、九種花色與原動畫、雙擊聊天、氣泡回覆、送達確認和失敗草稿。

## 驗證與限制

發布時以本版本來源 commit 對應的 GitHub Actions 結果為準。驗證涵蓋完整包、單檔 EXE、Setup 安裝後 App 的訊息、鍵盤操作、實際視窗位置移動及暫停散步，以及獨立 Windows runner 的實際防火牆規則、重複設定、網域規則保留、自訂封鎖失敗與復原。

自動測試的網路訊息仍是同機兩個程序；中文輸入法保護包含合成組字事件測試，實際注音／倉頡／拼音仍需現場驗收。兩台教室電腦、UAC 接受／取消，以及學校 AP／VLAN 隔離仍需現場確認。

**請使用 Setup 取得自動防火牆設定。** `NekoChat-Lite.exe` 為免安裝版，不會自行要求管理員權限或修改防火牆。

此版本仍是未簽署的 Windows x64 預發布測試版，無法保證 Windows SmartScreen 不提示，也不能取消學校的系統管理限制。內網聊天仍使用明文 TCP。
