## 本版更新

### 修正：關閉視窗時出現「無法完成存檔」（#29）
- 一般操作關閉 NekoChat 時，偶爾會跳出「關閉前無法完成存稿。這次不關閉…」而無法正常結束。原因是關閉流程中課堂檔案服務被第二次釋放時發生例外，被誤判為存稿失敗。現在重複釋放是安全的，正常關閉不再跳出這個警告。
- 關閉前儲存課堂草稿時，如果資料庫裡已經是相同內容，會視為已儲存，不再誤報「草稿無法儲存」。
- 真的發生關閉失敗時，會記錄診斷資訊並在提示中附上錯誤代碼，方便回報。

### 設定頁精簡：移除「課堂反應」區
- 設定頁不再顯示「課堂反應」整區：「這台是老師的電腦」勾選、「收到課堂反應時跳出貓咪圖」開關、「提醒螢幕」下拉都已移除。
- 為什麼：教室實際用硬體廣播，老師電腦只有一個螢幕；多問一個「貓咪要跟哪個螢幕」只會讓人困惑，其餘兩項在教學現場也用不到。
- 行為：貓咪圖固定出現在貓咪所在的螢幕；老師電腦仍由 IP（192.168.24.240）或課堂檔案節點自動辨識，老師電腦收到「講太快了」等 4 款反應照常跳出貓咪圖，其他電腦不跳。「你再給我滑！」照舊。
- 相容：舊設定檔照常載入。如果你曾在舊版把貓咪圖關掉，本版沒有介面可以重新打開，仍維持關閉。

## 升級注意
- 從舊版貓咪按右鍵選「離開」，再執行本版 Setup。資料庫沿用 beta.13 的格式，不需要額外遷移。

## 審查與自動化驗證
設定頁精簡（PR #31）與關閉存檔修正（PR #30）均通過 GitHub Windows runner 上的完整建置與原生 WPF 自動操作測試（安裝版與免安裝版）。CI 一律使用隔離 profile 與合成資料。
