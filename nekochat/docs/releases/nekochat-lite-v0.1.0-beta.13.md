## 本版更新

### 聯絡人
- 名單外的人第一次傳訊息時，會自動成為學生聯絡人，原本的「名單外」對話併成同一條，不會分成兩條。自動加入的聯絡人不會取得老師身分，也不會自動下載他傳來的附件。
- 「＋ 新增對象」可以一次填好 IP 和本機備註；新增重複的 IP 時，會直接打開既有的對話。
- 右鍵選單和對話標題的 ⋯ 選單整合在一起，可以編輯本機備註、編輯 IP、設為老師、移除、封鎖。
- 移除的聯絡人會放進「封存」，可以查看歷史，但不能傳訊息；移除後畫面停在原本的清單。
- **全班名單**：第一次開啟、名單還是空的時候，會自動帶入教室的 IP 名單（只有 IP，沒有姓名或學號），並排除本機。設定頁的「載入全班名單」只會補上缺少的 IP，不會覆蓋備註，也會跳過你移除過的聯絡人。

### 老師
- 名單裡最多只有一位老師，固定置頂，可以設定、更換、取消或移除。
- 這台電腦是不是老師電腦，改成獨立判斷：IP 為 192.168.24.240 的電腦會自動視為老師電腦，也可以在設定頁「這台是老師的電腦」手動調整。

### 封鎖
- 新增本機封鎖。被封鎖的人傳來的訊息，對方畫面仍顯示「已送出」，但你這邊不會保存、不會通知，也不計入未讀；解除封鎖後不會補回。這只是本機過濾，不是身分驗證，對方換了 IP 就不受限制。

### 課堂反應貓咪圖
- **恢復預設顯示貓咪圖。** beta.9～beta.12 的開關預設關閉，而且藏在設定頁看不到，等於沒有圖。設定頁新增「課堂反應」區，可以關閉（例如投影時）。
- 講太快了、跟不上、聽不懂、再講一次這 4 款只會在老師電腦跳出貓咪圖；其他電腦收到時不跳出任何提醒，只在聊天紀錄留一行小字。「你再給我滑！」照舊，誰收到都會跳圖。
- 需要雙方都是 beta.7 以上版本。手動打字輸入「講太快了」不會被當成課堂反應。

### 訊息與已讀
- 每則訊息都有 ⋯ 選單，可以「從這台電腦刪除」；不能刪的時候會說明原因。刪除只影響這台電腦，不會收回對方已經收到的內容。
- 已讀回條改成預設開啟。曾經自己關閉的使用者，升級後仍維持關閉。對方重新連線後，未送出的回條會自動補送。
- 因為加入了封鎖，送出成功的文字改為「已送出」，不再寫「對方已儲存」。

### 圖片縮圖
- 依檔案內容判斷是否為圖片：PNG、JPG、GIF、TIFF、BMP 顯示縮圖；WebP、HEIC 需要電腦已安裝對應的解碼器，沒有時會顯示提示文字；ICO 不提供預覽。
- 只有接收完成、而且重新驗證 SHA-256 通過的檔案才會產生縮圖，縮圖在背景處理。無法預覽時一定會顯示說明文字，不會只留空白。

## 升級注意
- 從舊版貓咪按右鍵選「離開」，再執行本版 Setup。資料庫會自動升級（升級前會先自動備份）。**升級後舊版就無法開啟新版的資料**，請不要再退回舊版。
- 已經有名單的使用者，升級時不會自動合併全班名單，需要的話請到設定頁按「載入全班名單」。
