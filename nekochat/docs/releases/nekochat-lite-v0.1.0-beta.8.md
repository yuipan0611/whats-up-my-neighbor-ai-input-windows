# NekoChat Lite 0.1.0-beta.8：升級成功後自動清理舊程式

## 下載與安裝

建議下載 `NekoChat-Setup-win-x64.exe`。先從舊貓咪右鍵選「離開」，再安裝新版。設定、花色與內網收訊設定沿用 beta.7；Windows 管理員授權請由有權限的人員完成。免安裝版 `NekoChat-Lite.exe` 直接執行，不會自行設定防火牆，也不涉及本次的舊檔清理。

## 本版修正

- **升級成功後自動清除舊程式資料夾**：先前每次用 Setup 升級，`%LOCALAPPDATA%\Programs` 都會留下一份完整的 `.nekochat-previous-*` 舊版資料夾。本版先核對新版檔案，系統接受啟動要求後才清除舊版。
- **失敗時還原原版**：新版驗證失敗、無法啟動，或在啟動前關閉安裝器，都會還原原本的版本。
- **自訂檔案先保留再清理**：舊資料夾中自訂、修改過或無法確認歸屬的檔案，會先複製並核對雜湊，保存在 `%LOCALAPPDATA%\NekoChat.WindowsLite\UpgradePreservedFiles`，安裝完成時會顯示位置。被鎖住、複製失敗或含連結的資料夾不刪除，並提示剩餘位置。
- 舊版安裝器留下的備份，只在完整程式結構可辨識時處理；未知名稱的資料夾、「下載」資料夾與免安裝版 EXE 都不會被刪除。
- 新版安裝會附帶檔案清單，後續升級可據此安全移除過時的程式檔。

## 未變更

- 更新方式仍是 App 自動檢查並通知新版，由使用者下載並執行安裝檔；沒有新增背景自動下載或安裝。
- 聊天、反應貼圖、動畫、散步與防火牆設定行為與 beta.7 相同；老師與同學不一定要同時升級。

## 驗證與限制

核心 3,966 項檢查（新增 46 項替換／還原／清理邊界）在 macOS、Linux 與原生 Windows 通過；原生 Windows 上以 Setup 進行全新安裝與升級，包含新版實際啟動、舊資料夾清除、測試用自訂圖檔與設定保留及捷徑驗證。真實教室電腦上的升級與 UAC 操作仍需現場確認。

此版仍是未簽署的 Windows x64 預發布測試版。標準語音版的三項既有測試失敗另外記錄，本次未修改標準版。
