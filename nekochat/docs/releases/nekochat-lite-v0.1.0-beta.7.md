# NekoChat Lite 0.1.0-beta.7：去背反應貼圖與兩秒中央提醒

## 下載與安裝

建議下載 `NekoChat-Setup-win-x64.exe`。先從舊貓咪右鍵選「離開」，再安裝新版；老師與同學兩端都請更新至 beta.7，才能看到圖片效果。

安裝沿用 beta.6 的內網收訊設定：Windows 管理員授權請由有權限的人員完成。完成後 App 以原使用者權限啟動，日常聊天不需管理員權限。免安裝版 `NekoChat-Lite.exe` 直接執行，不會自行設定防火牆。

## 新增功能

- **五款去背梗圖**：「講太快了」「跟不上」「聽不懂」「再講一次」「你再給我滑！」。貼臉圖保留右下角淺色前景，文字使用白字黑邊。
- 上面四款學習反應快捷傳給老師，預設老師 IP 為 **192.168.24.240**；可在聊天室修改並記住。
- 「你再給我滑！」傳給當前選定的聊天對象，老師與同學皆可使用；快捷貼圖保留正在編輯的文字草稿。
- **中央提醒放大 1.5 倍、停留兩秒**：沿用同一個桌面貓咪視窗，顯示反應後回復原貓咪、大小與位置；可指定投影或其他提醒螢幕，預設跟隨貓咪所在螢幕。拖曳及右鍵選單操作期間延後顯示。
- 同款反應合併計數，不會持續延長同一次提醒。完整短句也能觸發，例如「講太快了」「跟不上」「聽不懂」「再講一次」「你再給我滑！」；一般句子不做情緒判斷。
- **圖片與普通氣泡不附來源 IP，IP 只在聊天室顯示**；點圖片或氣泡仍能回覆真正發送者。
- 去背圖片內建在程式中，免安裝版只需一個 EXE。舊版仍可收到文字，看到圖片需更新至 beta.7。
- 保留 beta.6 的 Enter 傳送／Shift＋Enter 換行、中文組字保護、九色動畫與自動散步設定、送達確認、離線草稿保留及 Setup 網路設定。

## 使用方式

1. 老師與同學啟動 beta.7，確認聊天室顯示「接收已啟動」。
2. 核對「老師 IP」為 `192.168.24.240`；如有更動，輸入後按「記住老師」。
3. 同學點四款學習反應即可傳給老師；「你再給我滑！」請先在上方選好聊天對象。
4. 老師可在「提醒螢幕」指定投影畫面。收到反應時圖片出現在中央，兩秒後回復原位置；點圖片可立即回覆。

## 驗證與限制

本次來源的 Lite Windows／Relay CI 須先通過，才發布同一主線來源的附件。驗證包含完整套件、只放一個 EXE 的免安裝版及 Setup 安裝後 App 的真實雙程序收發、五款按鈕、兩秒回位、文字可見性、IP 顯示範圍、點圖回覆，以及原鍵盤／滑鼠／散步與安裝更新測試。

兩台實體教室電腦、投影與混合 DPI、顯示器拔除、實際中文輸入法及 UAC 操作仍需現場驗收。學校 AP／VLAN／管理政策可能影響連線；內網聊天沿用明文 TCP 8768。

此版仍是未簽署的 Windows x64 預發布測試版。標準語音版的三項既有測試失敗另外記錄，本次未修改標準版。
