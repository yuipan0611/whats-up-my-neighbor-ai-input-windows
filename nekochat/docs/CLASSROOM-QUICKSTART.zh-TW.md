# NekoChat 教室測試操作單

日期：2026-10-27｜適用版本：NekoChat Windows Lite 0.1.0-beta.1｜Windows 10/11 x64

老師建立一個教室房間，全班加入。學生可 Ping 老師，或輸入同學內網 IP 私訊。訊息只送指定收件人的 App；老師以 Teams 分享自己的畫面時，全班才能透過分享看到老師收到的發言。

本次只測文字：不需要麥克風、不需要 Groq API Key，也不用另外安裝 Python、.NET 或 Git。

## 下載與準備

- [直接下載 Windows 安裝檔 EXE](https://github.com/yuipan0611/whats-up-my-neighbor-ai-input-windows/releases/download/nekochat-lite-v0.1.0-beta.1/NekoChat-Setup-win-x64.exe)；[Release 版本頁](https://github.com/yuipan0611/whats-up-my-neighbor-ai-input-windows/releases/tag/nekochat-lite-v0.1.0-beta.1) 同時提供校驗碼與操作單。公開 Release 附件不需 GitHub 帳號，也不受 Actions 測試產物保存期限影響。
- 老師可先下載一次，依學校允許的方式把同一份 EXE 安裝檔交給全班；學生也可直接使用上述連結下載。
- 先準備老師＋兩位學生的電腦，測通後再擴大到全班。所有人用同一版 App，並能連到老師的教室主機。
- 若已有舊版 NekoChat 在執行，先右鍵貓咪 →「離開 NekoChat」，再更新。學校若阻擋安裝或網路存取，請教室管理者協助，不停用安全防護。

## 老師操作

### 1. 安裝並啟動

1. 從上方 Release 連結下載 `NekoChat-Setup-win-x64.exe`，不需解壓縮。
2. 雙擊 `NekoChat-Setup-win-x64.exe`，按「安裝並啟動」。
3. 在 App 按「跳過語音，先用文字聊天」。不用填任何 API Key。
4. 之後可從 Windows 開始功能表的「NekoChat Windows Lite」開啟。

### 2. 建立全班共用房間

1. 在「開始使用」按「建立教室房間（老師）」。
2. 按「複製邀請碼」，只分享給本班同學。全班使用同一份完整邀請碼，開頭應為 `NEKOCLASS1-`。
3. 請同學貼上邀請碼後按「加入房間」。學生不要各自建立新房間。
4. 老師切到「聊天」頁，保持 App 與電腦網路運作。聊天頁及貓咪氣泡會顯示學生來源 IP。

### 3. 接收、回覆與 Teams 分享

1. 請學生 A、B 各輸入一則含座號或暱稱的測試文字，再按「Ping 老師／傳送草稿」。
2. 老師確認兩則都出現在聊天頁，來源 IP 正確。多則氣泡會排隊，聊天頁可即時查看最近訊息。
3. 點某位學生的貓咪氣泡，自動選好該學生 IP；輸入回覆，按「傳送」。
4. 依平常方式在 Teams 分享老師畫面。請另一位同學確認 Teams 中看得到聊天頁與氣泡；若看不到氣泡，改分享貓咪所在的整個螢幕。

### 4. 三台電腦驗收

請先核對班上 IP 表與 App 顯示的 IP，以下示例不是實際位址。

| 測試 | 應看到的結果 | 勾選 |
|---|---|---|
| A Ping 老師：「A 測試發言」 | 老師收到；B 的 App 不收到副本 | □ |
| B Ping 老師：「B 測試發言」 | 老師收到；A 的 App 不收到副本 | □ |
| 老師點 A 氣泡回覆 | 只有 A 收到，收件 IP 是 A | □ |
| A 填 B 的 IP，按「傳送」 | 只有 B 收到；老師 App 不顯示此私訊 | □ |
| B 點氣泡回覆 A | 只有 A 收到 | □ |
| A、B 接近同時 Ping 老師 | 老師收到兩則，氣泡回覆不會選錯來源 | □ |

### 5. 結束測試

先記錄成功／失敗項目；退出 App 後，本次聊天紀錄不保留。老師按「取消／離開房間」或右鍵貓咪 →「離開 NekoChat」，會讓整間教室斷線，舊邀請碼失效。下次需建立新房間並分享新邀請。關閉聊天視窗只會收起視窗，不等於退出 App。

## 同學操作

### 1. 安裝

1. [直接下載同一版安裝檔 EXE](https://github.com/yuipan0611/whats-up-my-neighbor-ai-input-windows/releases/download/nekochat-lite-v0.1.0-beta.1/NekoChat-Setup-win-x64.exe)，或取得老師提供的檔案；不需解壓縮。
2. 雙擊 `NekoChat-Setup-win-x64.exe`，按「安裝並啟動」。
3. 按「跳過語音，先用文字聊天」。不用麥克風，不填 Groq Key。

### 2. 加入老師的教室

1. 取得老師給的完整 `NEKOCLASS1-` 邀請碼。
2. 在「開始使用」貼到「同學給你的邀請碼」，按「加入房間」。不要自己建立房間。
3. 等待已連線，進入「聊天」頁。核對「我的教室 IP」與「老師」IP；收件人預設為老師。

### 3. Ping 老師

1. 在訊息草稿輸入：「座號／暱稱：老師，我有問題。」
2. 按「Ping 老師／傳送草稿」。這顆按鈕會把目前草稿送給老師，即使原先填的是其他同學 IP。
3. 確認顯示「已送達對方連線（非已讀）」。老師收到的畫面若正在 Teams 分享，全班就能透過分享看到。

### 4. 私訊同學與回覆

1. 確認對方已加入同一間教室。
2. 在「對方內網 IP」填完整 IP，例如 `192.168.1.22`（僅示例），不要加 `http://` 或埠號。
3. 輸入「A → B 私訊測試」，按一般的「傳送」，不是「Ping 老師」。
4. 對方收到貓咪氣泡後可點擊回覆；確認收件 IP，再輸入回覆並按「傳送」。
5. 回覆同學時請用「傳送」；「Ping 老師」永遠會改送給老師。

只有收件人的 App 收到這則私訊；老師 App 不額外收到副本。LAN 是可信內網傳輸，並非端到端加密；本次請用測試文字。

## 現場問題快速檢查

| 狀況 | 先做這件事 |
|---|---|
| 找不到房間／加入逾時 | 確認老師房間仍開著、邀請碼完整、使用同一新版 App，且教室網路能連到老師主機。仍失敗請管理者檢查防火牆、AP／VLAN 隔離。 |
| 邀請碼不相容 | 新教室邀請是 `NEKOCLASS1-`；舊版 `NEKO1-` 雙人邀請不能使用。全班更新同一安裝包。 |
| 顯示這台 IP 已在房間 | 先離開同電腦上的舊 App，再重新加入；非正常斷線時最多等待 90 秒。每個來源 IP 限一個身分。 |
| 傳不到某位同學 | 核對 App 顯示與班上 IP 表；對方必須已加入同一房間，且不是填到自己的 IP。使用完整私有 IPv4。 |
| 沒看到氣泡 | 先開「聊天」頁看最近訊息，再確認桌面貓咪仍在。多則氣泡會依序顯示，點氣泡可回覆並接續下一則。 |
| 未收到送達回條／連線中斷 | 草稿會保留。先向對方確認是否收到，再決定是否重送，避免連按造成重複訊息。 |
| 老師離開後全班斷線 | 房間由老師 App 維持，這是預期行為。請老師重新建房，再用新邀請碼加入。 |
| Windows 阻擋安裝或連線 | 請教室管理者依學校規範審核與允許；不要停用防護或自行繞過網路隔離。 |
