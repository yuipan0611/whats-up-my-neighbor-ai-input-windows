# NekoNode / NekoChat Windows Lite (教室輕量版)

專為電腦教室與區域網路設計的 Windows 桌面貓咪與局域網即時通訊小工具。

## 0.1.0-beta.9 教室測試版

- 內建花色預設自動散步，不再被 Windows 視窗動畫設定停用；右鍵「🐾 自動散步」可暫停／恢復並記住選擇，隨機目的地、緩加速／減速及依距離播放腳步。
- 播放與散步流程對齊 Mac 原生動作順序；沿用同源影格。平台差異見 [動畫比對](../docs/LITE-ANIMATION-PARITY.md)。
- Enter 傳送、Shift＋Enter 換行；修正多行輸入框攔截 Enter 的事件順序，保留中文選字確認。
- 建議下載 Setup：安裝時透過一次管理員授權，自動建立同網段 TCP 8768 的精確程式規則，並處理舊版對應程式的預設 TCP 封鎖。App 日常執行仍不需管理員權限。
- 取消授權可重試或略過；學校自訂封鎖／管理政策會顯示未完成，不能視為內網已通。
- 單檔免安裝版不自動修改防火牆。SmartScreen、學校權限、兩台實體電腦及實際中文輸入法仍需確認。
- 完整修改說明：[beta.9 發布說明](../nekochat/docs/releases/nekochat-lite-v0.1.0-beta.9.md)。

## beta.5 已有功能

### 課堂反應貼圖

- 「講太快了／跟不上／聽不懂／再講一次」四個快捷按鈕傳給老師，預設老師 IP 為 `192.168.24.240`，可在聊天室修改並記住。
- 「你再給我滑！」傳給目前選定的對象，雙方都能使用。按貼圖不清空正在編輯的文字草稿。
- 老師收到上述學習反應，或接收方收到「你再給我滑！」時，同一個桌面貓咪視窗在指定螢幕中央顯示已確認的去背梗圖，放大 1.5 倍、停留兩秒，再恢復貓咪外觀與位置。可選提醒螢幕，預設跟隨貓咪；拖曳與選單操作期間延後提醒。
- 同款反應合併計數，不延長當次提醒；普通聊天仍使用原氣泡。圖片與普通氣泡不附來源 IP，聊天室保留 IP；點圖片仍可回覆真正發送者。
- 支援完整短句觸發，例如「講太快／講太快了／太快了」「跟不上／我跟不上」「聽不懂／我聽不懂」「再講一次／請再講一次」「你再給我滑！」；忽略句尾標點，避免將「不會太快」等一般句子誤判。
- 舊版只會顯示文字，兩端都使用新版才能看到圖片效果。本功能使用原 TCP 8768，不新增外網服務。

詳細設計與驗證狀態見 [課堂反應紀錄](../docs/CLASSROOM-REACTIONS.md)。

純文字 IP 直連：沒有語音輸入、麥克風、Groq、API Key、建房或邀請碼。保留九種花色、原動畫、雙擊開啟聊天及氣泡回覆。主視窗標題直接顯示版本。

- 重複開啟會提示使用現有貓咪，不再建立第二個收不到訊息的視窗。
- 下方持續顯示「接收已啟動」或接收失敗原因。TCP 8768 被舊版或其他程式占用時，按鈕與 Enter 都不能傳送，請先從舊貓咪右鍵離開後重開。
- 對方沒有確認送達或回覆格式不正確時，保留草稿並顯示原因。傳送中不接受重複 Enter，完成後保留你剛輸入的新草稿。
- 完整套件、免安裝 EXE、Setup 安裝後 App 均驗證兩程序雙向傳訊、氣泡回覆、重複啟動及接收埠占用；這是同台 Windows 的自動測試，仍需兩台教室電腦實測。

雙方測試前先從貓咪右鍵「離開」舊程式，再開啟相同的 beta.9。傳訊使用 TCP 8768；請確認接收端顯示「接收已啟動」。若連線失敗，依提示請教室管理者檢查網路權限與 AP／VLAN 隔離。

- **下載即用**：提供單一免安裝綠色執行檔 `NekoChat-Lite.exe`，雙擊直接啟動，不需要安裝 Python、.NET 執行環境或設定 API Key。
- **純內網直連通訊**：不要求長邀請碼或建立房間；在同一個 Wi-Fi／教室內網中，直接輸入同學的內網 IP（例如 `192.168.1.25`）即可互傳文字。
- **桌面貓咪氣泡通知**：收到訊息時，桌面上的貓咪會即時冒出對話氣泡，顯示同學名稱與發言；點擊氣泡即可帶入對象直接回覆。
- **本機通訊錄名單**：支援在輸入 IP 旁記住「同學姓名／座位標籤」（例如 `192.168.1.25 -> 隔壁小明`），自動儲存在本機 `%LOCALAPPDATA%\NekoChat.WindowsLite\settings.json`。
- **開機自動啟動**：作為桌面寵物，可勾選開機自動啟動（寫入 Windows 登入註冊表 `HKCU Run`），開機小貓就出現在桌面上陪伴。
- **9 種貓咪花色隨選**：支援 9 種原生花色（原版黑貓、純黑貓、純白貓、灰貓、橘虎斑、賓士貓、三花貓、玳瑁貓、重點色貓），可在視窗調色盤或右鍵選單點選即時切換，完整保留原版散步、抓起、摸摸等動畫。
- **無語音、純淨輕量**：徹底移除語音辨識、麥克風錄音、Groq API 與外部服務依賴，適合無外部網路連接或安靜無麥克風的教室環境。

## 升級與舊檔清理

自 beta.9 起，從貓咪右鍵選單「檢查更新…」同意下載後，會直接取得並驗證安裝檔，顯示進度與取消按鈕；完成後可選擇開啟安裝並關閉 App。beta.8 以前的使用者需先手動下載 beta.9 升級一次。新版驗證與啟動要求成功後會清除舊程式備份；失敗則還原。個人設定保留；混在舊程式資料夾的自訂素材或未知檔案會先核對內容，保存在 `%LOCALAPPDATA%\NekoChat.WindowsLite\UpgradePreservedFiles`。無法安全清除的檔案會保留並顯示位置。詳見[升級與清理規則](../docs/UPDATES.md#lite-安裝後舊檔清理)。

## 下載與使用

1. 建議下載 `NekoChat-Setup-win-x64.exe`，按「安裝並啟動」並同意一次管理員授權，讓安裝程式設定同網段收訊。單檔 `NekoChat-Lite.exe` 不自動設定防火牆。
2. 雙擊開啟，桌面右下角會浮現可愛的透明桌面貓咪，同時開啟主視窗。
3. 主視窗上方清楚標示「我的內網 IP」（例如 `192.168.1.34`），可按「📋 複製我的 IP」直接報給隔壁同學。
4. 輸入對方的內網 IP 與訊息，按下 **🚀 發送訊息**（或按 Enter 發送），對方桌面的貓咪就會跳出對話氣泡！
5. 點擊「🎨 選擇你的桌面貓咪花色」，可以立即切換為你喜愛的貓咪毛色。
6. **雙擊貓咪左鍵**開啟聊天視窗；單擊與拖曳放開不開啟。訊息氣泡仍可單擊回覆，右鍵選單也可開啟聊天。

## 雙版本定位說明

本專案在 Windows 平台提供兩個清晰定位的版本：
- **標準版 (`Neighbor.Windows`)**：個人 AI 語音輸入工具。具備全系統全域快捷鍵（Ctrl + Alt + Space）錄音輸入、Groq Whisper Large v3 語音轉文字、自訂詞庫、智慧修字提示學習與桌面黑貓。
- **Lite 教室版 (`NekoChat.WindowsLite`)**：教室局域網通訊工具 + 桌面多花色寵物。純 C#、免邀請碼、免外網、免麥克風、開機自啟動、多花色隨選。

## 訊息驗收（每次 Windows 建置必跑）

`NekoChat Windows Lite` CI 必須執行訊息測試後，才能回報聊天功能通過：

- 核心測試使用真實 TCP：雙向中文、emoji、多行文字、來源 IP、送達回覆、連接埠被占用、對方離線，以及 HTTP 成功但沒有送達確認的情況。
- Windows 測試對完整套件、免安裝 EXE、安裝器實際解壓後的 App，各啟動兩個獨立程序，觸發實際 Enter 與「傳送」按鈕，走 SQLite attempt 與儲存 ACK。檢查正文原文、預設提醒僅顯示姓名與「新訊息」、ACK 後草稿清空；逾時保留草稿與單次嘗試，再關閉重開資料庫驗證。此入口已列歷史測試，fixture 上限跟隨已確認的 D-06：65,536 UTF-8 bytes；不代表新版教室 transport 或 Windows 原生流程已通過。
- 反應測試先驗證隱私預設，再從實際設定勾選允許反應圖片後，檢查五款素材、恢復位置與舊版來源的獨立未驗證紀錄。
- 每一種包裝也使用 Windows 原生滑鼠輸入，驗證單擊貓咪不開視窗、雙擊只開一次，以及第二次按住拖曳後放開不誤開視窗。
- 兩端報告與聊天／氣泡／錯誤畫面保存於 `nekochat-windows-smoke-captures` artifact；原先的 `--smoke-test` 只涵蓋 UI 與素材，不能當成訊息已送達的證據。

在拋棄式 Windows 測試帳號，建置後可執行（請使用全新的輸出目錄）：

```powershell
./scripts/test-lite-messaging.ps1 -App ./build/windows-lite-package/NekoChat.Windows.exe -OutputDirectory ./build/windows-lite-smoke/manual-messaging
```

測試使用同台 Windows 的兩個程序和不同本機測試埠；正常聊天仍使用 TCP 8768。這項結果不代表教室 AP／VLAN／防火牆已通過。發布前仍需兩台實體 Windows 電腦互傳、點氣泡回覆，並確認對方離線時不顯示成功。測試使用輸出目錄內獨立的 SQLite 與設定，不讀寫日常設定。請仍使用拋棄式 Windows 測試帳號驗證原生視窗。


## 離線備份還原

App 提供 `--restore-backup <獨立備份.db> <全新目錄>`，只在新目錄產生經驗證、升級與重開的副本。既有資料與原備份均不覆寫。操作方式與安全切換步驟見 [BACKUP-RESTORE.md](BACKUP-RESTORE.md)。Mac 核心測試已實際涵蓋複製／驗證／發布前後的程序終止；Windows CLI、檔案權限與人工切換尚待原生驗收。
