# NekoChat Windows Lite 0.1.0-beta.11 候選

下一版修復候選，尚未發布。公開版目前為 beta.10。Windows 教室／區網聊天與桌面貓咪，提供未簽署的 x64 預發布測試版。[完整更新說明](https://github.com/yuipan0611/whats-up-my-neighbor-ai-input-windows/releases/tag/nekochat-lite-v0.1.0-beta.10)。

## 開始使用

1. 先從舊貓咪右鍵「離開」，再安裝 `NekoChat-Setup-win-x64.exe`；免安裝版可直接執行 `NekoChat-Lite.exe`，保留九種花色與散步。Setup 的收訊防火牆設定須由有權限者同意；免安裝版不自動改防火牆。
2. 雙擊貓咪開啟聊天。按「新增對象」輸入對方內網 IP；老師使用「加入老師」。設定可查看／複製自己的 IP。右鍵名單可編輯本機綽號。
3. 選定聊天室後傳訊，Enter 傳送、Shift＋Enter 換行。老師置頂；課堂反應只在老師聊天室傳送，同學貼圖只傳給目前對象。
4. 拖一個檔案、按迴紋針或 Ctrl＋V 貼截圖，先看到附件，再按傳送。每則一個，上限 25 MiB，可不附文字。詳見 [附件說明](ATTACHMENTS.md)。
5. 「課堂檔案」為全班共用區，老師與同學皆可上傳；該頁拖入後放開即分享，只有自己的分享顯示撤下。私人聊天附件不會自動成為共用檔案。

## 附件、課堂分享與隱私

- 真正傳送檔案內容並核對 SHA-256；通知已到不等於檔案已收完。名單內 5 MiB 以下附件自動下載，較大或名單外來源點「下載」。檔案不自動執行／開啟。
- App 附件總額度 512 MiB，包含草稿與備援。額滿提示清理；清理不刪除另存到外面的檔案。已入列附件暫時中斷後自動續送；舊失敗紀錄可手動重試。暫不支援資料夾或多檔批次。
- 老師優先同步課堂分享，同學節點可提供備援與接管；沒有任何完整在線來源時無法下載。撤下無法收回別人已另存的副本，離線節點回線後才同步。
- 公開程式不內建真實班級姓名、學號或 IP。班級專用完整包的 `classroom-roster.csv` 另行私下發放，首次空名單才會套入，不覆蓋個人綽號。
- 以本機名單與實際連線 IP 歸屬，沒有帳號或數字配對；IP 或老師標籤不是身分證明。區網內容未加密，SHA-256 不是加密。
- 預設通知不顯示訊息正文；聊天紀錄、綽號與草稿存本機。失敗／重試在該則訊息卡顯示。

## 升級與故障

beta.9 可經「檢查更新…」同意下載，驗證 SHA-256 後再同意執行安裝；beta.8 或更舊版請手動下載 beta.10。安裝升級保留設定與已確認的自訂檔案；不要同時執行舊、新兩個正式 App。

正常通訊埠為 TCP 8768。埠被占用、學校政策或 AP／VLAN 隔離會阻止連線，請依錯誤提示處理，不把 TCP 可達或雲端測試當成教室驗收。

附件儲存故障時會停用附件並保留草稿，文字聊天仍可使用；修復權限／磁碟或檔案鎖定後重新啟動。待傳附件須先明確移除才能改傳文字。資料庫本身損壞、無法寫入或升級失敗時會停止收發，原始資料保留，不會假裝送達。

資料庫升級後舊程式不能直接開啟，回退請使用升級前備份；資料庫備份不含附件檔案，重要檔請另存。[備份還原](BACKUP-RESTORE.md)／[交付與驗證](DELIVERY.md)。

## 驗證界線

Core 真 TCP／SQLite 與 Windows CI 涵蓋收發、草稿、SHA-256、三節點課堂分享／撤下、原生視窗／滑鼠／鍵盤、封裝／portable／安裝後程序、更新與安裝升級。Parallels 已有真正檔案總管拖入聊天室及課堂區的證據。

兩台 Windows、真實教室 AP／VLAN／多人負載、其他實際 DPI／多螢幕與實裝中文輸入法仍需現場驗收。舊版文字聊天保持相容；附件與課堂分享需雙方版本支援。

Lite 不包含標準版 Neighbor 的語音、Groq 或 API Key 功能。保留原核准貓咪素材與動畫；授權見 [第三方說明](THIRD-PARTY.md) 及專案 MIT LICENSE。

## 本批修復候選（尚未發布）

- 按傳送先保存在本機待送，再清空該次輸入；暫時斷線後自動續送，新草稿不受影響。舊失敗紀錄保留，可明確手動重試。
- 右鍵訊息可選「從本機刪除…」；只影響本機，對方的訊息不會被收回。失敗卡也可刪除；新草稿與新附件保留。較早的失敗訊息可透過載入較早訊息分頁查看。
- 暱稱沿用名單右鍵「編輯綽號…」，僅保存在這台電腦，不改對方 IP 或訊息歸屬。

本機問題排除：設定 →「匯出診斷記錄」。診斷只保存在本機，不含聊天／附件內容，不會自動上傳。詳見 [診斷與故障處理](DIAGNOSTICS.md)。
