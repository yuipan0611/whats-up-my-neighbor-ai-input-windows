# 真實附件（本機測試候選）

本分支補上拖曳、迴紋針選檔、Ctrl＋V 截圖的真正位元組傳輸；不是 beta.9 已發布功能的回溯聲明。尚未正式發布、安裝或完成兩台 Windows 驗收。

## 使用方式

選一位同學，拖入一個檔案、按迴紋針，或在草稿內貼上截圖。先看到待傳附件，再按傳送；可以不輸入文字。每則一個附件，單檔25 MiB（畫面顯示 MB）；不支援資料夾、多檔批次或續傳。文字仍限64 KiB。

名單內同學的5 MiB以下附件自動下載；較大或名單外來源先顯示卡片，點「下載」才取得內容，不彈接受視窗。發送端需在線並保留 App 附件副本。對方舊版不支援時，會提示更新並保留草稿，不退回檔名標籤。

「等待對方下載」只代表通知已存下。「附件已送達」須對方收完、驗證大小和SHA-256並回覆確認；收件端確認回覆失敗時可「重送確認」。取消不撤回已確認的事實。檔案不會自動開啟或執行。

草稿與已接收檔重開後仍在。App 附件空間上限512 MiB，含暫存和草稿；額滿會拒絕下載，不自動刪除完成檔。「清理附件空間」刪除歷史附件的本機副本，保留待傳草稿、文字歷史及你已另存的檔案。移除草稿留下的未引用快照，在下次啟動或清理空間時回收。傳輸中斷後由人手動重試，從頭下載。

## 協定與儲存

既有教室文字協定與凍結向量不改。hello 增加 attachments.v1 能力；同一TCP埠的 /nekochat/attachments/v1/offer、chunk、complete 使用獨立envelope。offer 綁一次性教室session；下載權杖綁messageId和實際來源IP，chunk最多256 KiB。每台一條下載lane、一條供檔lane；listener另限制兩個附件請求及每來源2400次／分鐘，文字quota獨立。

附件先寫.part、檢查長度和雜湊、Flush與原子更名，再提交完成狀態。migration11新增附件及附件草稿表、對話附件世代；凍結migration1不改。清除對話保留messageId tombstone並推進附件世代，晚到工作不得重建內容。相同offer不重複通知，名單合併保護附件草稿衝突。

依既有教室IP模式歸屬；沒有新增配對、帳號、伺服器或加密。SHA-256驗證內容一致，不是對方身分證明。日誌與ToString不印下載權杖。現有SQLite備份不包含附件檔案；恢復只有資料庫時，缺少的附件副本會標示不可用，重要檔請另存。舊程式不能直接開migration11資料庫，回退時須使用升級前備份。
