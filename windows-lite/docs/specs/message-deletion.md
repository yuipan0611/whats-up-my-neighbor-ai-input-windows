# 訊息本機刪除（MD）

決策：D-26 的本機刪除部分。雙方收回在第 2 批（recall.v1），本批不得出現任何「收回」字樣或暗示對方已刪除。

**MD-01 每則訊息都找得到刪除** 【WPF】
- Given 對話中任一則已存訊息（文字、程式碼、圖片、檔案；自己送的或收到的）
- When 滑過訊息出現的 ⋯ 按鈕，或在訊息任何位置（含正文文字區）按右鍵
- Then 看得到「從這台電腦刪除」

**MD-02 刪除只影響本機**
- When 確認「只從這台電腦刪除，不會收回或刪除對方已收到的內容」
- Then 訊息從本機畫面消失；對方畫面不變；同一 messageId 之後重送不會復活（沿用 `ClassroomCleared` 墓碑）

**MD-03 不能刪時說明原因** 【WPF】
- Given 訊息正在傳送中，或視窗正在切換對象／關閉中
- When 打開該則訊息的操作
- Then 「從這台電腦刪除」顯示為停用並附原因（例如「傳送中，完成或停止後才能刪除」），不再出現點了沒反應的情況

**MD-04 待送訊息可停止並刪除**
- Given 待送／失敗／未確認的訊息
- When 選「停止傳送並刪除」
- Then 同一交易內停止後續重試並刪除；其他待送與較新的草稿不受影響
- And 提示「若對方已經收到，對方那份不會被刪除」

**MD-05 附件三種動作分清楚** 【WPF】
- 草稿附件：「移除附件」（尚未送出）
- 傳輸中：「取消傳輸」
- 已存訊息：「從這台電腦刪除」
- Then 三種文字與位置不混用
