# 老師（TC）

目標：老師永遠只置頂一筆，不會在同學區出現第二條，也能正常更換或移除。不改線上協定。

**TC-01 把既有聯絡人設為老師**
- Given IP `T` 已是學生聯絡人或存在 `ip:T` 對話
- When 使用者選「設為老師」（或「＋ 加入老師」輸入 `T`）
- Then 原本那筆升級為老師並置頂；`ip:T` 歷史依 CT-02 合併；同學區不再有 `T`
- And 歷史、草稿、未讀全部保留

**TC-02 同時只有一位老師**
- Given 已有老師 `T1`
- When 把 `T2` 設為老師並確認「將取代目前的老師」
- Then `T2` 置頂，`T1` 降為學生聯絡人（仍在同學區、歷史保留），不會變成「已移除」

**TC-03 老師設定只有一個來源**
- When 設為／取消老師
- Then `RosterEntry.isTeacher` 與 `Settings.TeacherIp` 在同一個操作中一起更新；不再有隱藏的「記住老師」欄位與名單不一致

**TC-04 取消老師**
- Given 老師 `T`
- When 選「取消老師身分」
- Then `T` 回到同學區成為一般聯絡人；「＋ 加入老師」重新出現

**TC-05 移除老師**
- Given 老師 `T`
- When 依 CT-13 移除
- Then `T` 只出現在封存區，不會掉進同學區；「＋ 加入老師」重新出現

**TC-06 升級舊資料**
- Given 舊版資料庫有多筆 `isTeacher=1`，或老師 IP 同時有 `ip:` 對話，或刪除過的老師
- When 升級到新版並啟動
- Then 依「最近設定者優先（無法判斷時取 `Settings.TeacherIp` 對應者）」只保留一位老師，其餘降為學生；`ip:` 對話依 CT-02 合併；不刪除任何訊息
- And 遷移前自動備份資料庫（沿用現行升級備份）

**TC-07 CSV 名單種子**
- Given 空名單首次啟動，`classroom-roster.csv` 標示多位老師
- Then 只採第一位為老師，其餘當學生並記錄診斷；不破壞 TC-02
