# 已讀回條（RR）

決策：D-28（已讀預設開啟，修改 D-10 的預設值；「已送出的回條不可撤回」仍有效）。不改線上協定。

**RR-01 新安裝預設開啟**
- Given 全新安裝
- Then 「傳送已讀回條」為開啟

**RR-02 升級時尊重使用者原本的選擇**
- Given 舊版使用者從未手動改過回條設定
- When 升級
- Then 改為開啟，並在設定頁與首次開啟聊天視窗時提示一次「已讀回條現在預設開啟，可在設定關閉」
- Given 舊版使用者曾手動關閉
- Then 升級後維持關閉

**RR-03 對方回線後自動補送**
- Given 回條因對方離線重試超過 8 次而暫停
- When 再次與對方成功通訊（任一 hello／訊息往來成功）
- Then 該對象的回條重試額度重新啟動並補送，不必重開 App

**RR-04 公平排程**
- Given 前 50 筆待送回條都屬於離線的對象 X
- When 對象 Y 在線
- Then Y 的回條仍會送出，不被 X 卡住

**RR-05 關閉回條時不補送**
- Given 使用者關閉回條
- Then 佇列中尚未送出的回條不再補送；已送出的不撤回

**RR-06 已讀只在真正看到時送出**（既有行為，回歸保護）
- Then 依 beta.11 的閱讀定位規則：聊天窗在前景且訊息實際呈現才算已讀；背景或停在較早位置不送
