# LINE 對照驗收表（NekoChat Lite 業務驗收總表）

用途：以一般人最熟悉的 LINE 為參考，逐項檢查 Lite「聊天軟體該有的基本體驗」做到了沒有。每一列都要落到一個狀態，不能空白。

- 依據：beta.12 原始碼（fa5ef9c）、第 1 批規格、決策 D-24～D-28。2026-11-07 整理。
- **只對照使用者看得到的行為**，不複製 LINE 的介面或圖像。
- Lite 的前提：同一教室內網、點對點直連（沒有中央伺服器、沒有帳號）、IP 只是標示不代表身分。因此需要伺服器或帳號才能成立的功能，標為「刻意不做」並寫明原因。

狀態：
- ✅ 已有：已發布版本就有
- 🔧 第 1 批：開發中（不改協定）
- 📅 第 2 批：協定能力升級（profile／presence／recall）
- 📅 第 3 批：本機體驗補強
- ❓ 待決：需要使用者勾選要不要做
- ⛔ 刻意不做：架構上做不到或不適合，原因寫在備註
