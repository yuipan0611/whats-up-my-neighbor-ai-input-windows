# 課堂檔案共用候選 1：驗證與交付

2026-11-05。本機分支 `codex/lite-classroom-ux-20261105`。使用者已核准共用流程；已實作，不是只有 HTML 按鈕。尚未安裝、push、發布或部署。

## 行為與實作

- 左側老師下方為「課堂檔案」。老師與同學皆可明確上傳；私人聊天附件不會自動成為全班分享。上傳時先複製、計算雜湊，再提交分享紀錄。
- 每份分享用獨立 P-256 操作憑證，分享 ID 綁定公開金鑰。只有持有該份私人憑證的原分享者可撤下；IP、綽號與本機老師標籤不授予這項權限。Windows 私人憑證用 CurrentUser DPAPI 保護，並不建立舊版聊天金鑰或數字配對流程。
- SQLite additive migration 12：三張新 STRICT 表。不可變新增／撤下操作、私人憑證與本機檔案引用分開保存。撤下紀錄先到仍能擋住晚到新增，不靠電腦時鐘競爭；原文字格式、凍結向量及既有歷史保持。
- 新增同埠 `classroom-files.v1` 端點與能力宣告。各節點定期向名單內 IP 同步，老師優先，同學節點也可持續新增、下載、撤下自己的分享；老師回線後合併。目錄同步確認與完整檔案副本分開，未完整保存的來源不計入已確認在線副本。
- 目錄與內容分離。只從本機名單設定的 IP／埠取檔，不接受下載網址；臨時下載憑證綁定來源 IP 及分享 ID。下載到預留空間的 `.part`，比對長度、SHA-256 後原子移動及更新資料庫。取消／中斷後可手動從頭重試。
- 與私人聊天共用附件 vault、512 MiB 額度、一個下載及一個供檔通道、listener 附件配額；最大塊 256 KiB，供檔每塊另節流 30ms。單檔仍為 25 MiB。課堂備援會在額度內複寫共用檔案；私人聊天原 5 MiB 自動接收政策不變。
- 本機依穩定序號分頁，每頁 50 筆。上限 1024 份有效分享、16384 筆保留操作，額滿明確停止新增，不靜默刪除撤下紀錄。
- 「清理附件空間」可清除備援快取，保留目錄與仍提供中的自有分享；先撤下再清理可釋放自有檔案。別人已另存的副本無法收回，離線節點需回線後才同步撤下。
- HTTP/TCP 並非加密傳輸，也不證明老師真實身分。全網斷線或沒有任何完整來源時，不能取得檔案；介面不宣稱全班即時一致或所有人都已下載。
