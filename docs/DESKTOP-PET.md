# Windows 桌面小黑貓：第一階段

目標：沿用 macOS 版的原始素材與基本散步動作，在 Windows 工作區底部散步與休息。

## 已實作

- **預設關閉**，與 macOS 版第一次使用的狀態一致。系統匣「桌面小黑貓散步」可開關，偏好保存在既有設定檔（`DesktopPetEnabled`）。舊設定檔沒有此欄位時同樣為關閉。
- 原 macOS SVG 以內嵌資源方式放入程式（`assets/desktop-pet/`），來源與授權見該資料夾的 README。
- 腳掌偏移公式與身體彈跳公式與 `DesktopPetView.swift` 相同（已逐行比對）。
- 只有身體與尾巴隨方向鏡射；X 左眼與勾勾右眼不鏡射（已由測試輸出的影格目視確認）。
- 無邊框、不顯示於工作列、不取得焦點（`NonActivatingForm`，`WS_EX_NOACTIVATE`）。
- 使用逐像素 Alpha 的分層視窗（`UpdateLayeredWindow`，見 `LayeredWindow.cs`），不再使用色鍵透明，以避免抗鋸齒邊緣出現紫色外框。
- 只有貓咪身體接收滑鼠（以渲染影格的 Alpha 判斷，閾值 24）；透明區域依分層視窗行為穿透到後面的視窗。
- 按住貓咪身體可拖曳：保持抓取位置，拖曳中暫停散步；放開後停在新高度，只做水平散步，不會回到底部，也不會垂直漂移。
- 拖曳範圍限制在指標所在螢幕的工作區；螢幕改變或移除時會夾回可見範圍。擷取遺失或隱藏時會取消拖曳，不會卡住。
- 錄音、辨識、保留錄音期間隱藏；全螢幕前景、螢幕鎖定、休眠時隱藏，恢復後繼續。
- 遵循 Windows「動畫效果」設定，關閉時停止移動。
- 關閉功能時停止計時器；程式結束時取消 `SystemEvents` 訂閱並釋放資源。
- 桌寵若發生非預期錯誤，會自動停止並通知一次，不會每個計時週期重複彈出錯誤視窗。桌寵無法建立時，聽寫功能仍正常啟動。

## 與 macOS 版的差異

| 項目 | macOS | Windows 第一階段 |
|---|---|---|
| 散步速度 | 依距離在 2–9 秒內走完，使用平滑曲線，約 70 px/s 的設計速度 | 固定 55 px/s（100% DPI），每段最多 7 秒，走到邊界或超時就休息 |
| 散步範圍 | 可走到整個可用區域的邊緣 | 只在目前螢幕工作區底部 |
| 拖曳 | 有抓起與落下動畫 | 已實作拖曳，放開後只水平散步，沒有抓起動畫 |
| 點擊、舔掌 | 有 | 未實作 |
| 資料夾停靠、跨螢幕巡遊 | 有 | 未實作 |
| 睡眠、梳理、打哈欠等狀態 | 有 | 未實作，目前只有坐姿休息與散步 |

官網與發布說明不能宣稱與 macOS 版相同。

  - 移動模型的暫停、邊界、負座標螢幕、螢幕移除後的夾取、窄工作區。
