# NekoChat Lite beta.5：兩台電腦測試

1. 兩台都先在舊貓咪上按右鍵 →「離開」。關閉聊天視窗只會隱藏，程式仍在執行。
2. 兩台都安裝本次 `NekoChat-Setup-win-x64.exe`，按「安裝並啟動」。不需要 .NET、Python、麥克風或 API Key。視窗標題應顯示 `0.1.0-beta.5`。
3. 確認兩台下方都顯示「接收已啟動（TCP 8768）」。若顯示無法接收，先離開其他舊貓咪並重開；仍失敗請保存提示文字。
4. A 的對方 IP 欄填入 B 當下畫面上方的「我的 IP」，傳「A 傳給 B：你好 🐈」。不需要建房或邀請碼。
5. A 應顯示「已送達」且原草稿清空；B 應在聊天紀錄與貓咪頭上氣泡看到文字。
6. B 點氣泡，自動帶入 A 的 IP，再回「B 回覆 A：收到了 🐾」。確認 A 收到。
7. B 從貓咪右鍵「離開」後，A 再傳一次：應顯示未能確認送達並保留草稿。未確認送達時，先問對方再重送，避免重複。

## 若仍收不到

- 保存發送端完整視窗，包含底部的傳送狀態與接收狀態；同時記錄對方聊天紀錄是否出現文字。
- 確認填的是對方正在使用的教室網路 IP；有 VPN、多張網卡或更換 Wi-Fi 時，請管理者協助核對。
- 相同 Wi-Fi 仍可能被 AP／VLAN 隔離。管理者可在發送端執行 `Test-NetConnection 對方IP -Port 8768` 檢查 TCP 可達性；成功連線不等於聊天已送達。
- 程式不修改防火牆。請依教室規範處理網路存取權限。

此版為未簽署的 Windows x64 預發布測試版，傳訊為內網明文。自動測試使用同台 Windows 的兩個程序，兩台實體電腦與教室網路仍需依上述步驟驗收。
