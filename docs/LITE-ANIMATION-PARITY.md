# Windows Lite / macOS 桌面貓咪動畫比對

## 來源

Windows manifest 指向 Mac commit `ef9fe89f1f78698453ed13d3cfba4181fc326537`，renderer SHA-256 `ce8746f213326c1ad2aa9c829b30cb5f1c00ccf5c3eb100d4a18c46901b09eeb`。對照 Mac 1.4.9 主線 `99924bd997137c5b33a3cfb61c401bd8cf85f400`，此區間沒有更動 DesktopPet 繪圖、提起時序或素材。

Mac 使用 Swift 原生繪圖與 pickup PNG；Windows 將同一原生 renderer 的姿勢輸出為 PNG 影格並內嵌 ZIP，實際不是兩份不同 GIF。Windows 每種花色 397 張播放影格，九種共 3573 張，測試逐張核對存在性。提起／放下使用原生 28 個時序點與來源索引，完成放下停在來源 frame 35；沒有補畫或插值替代來源影格。

## beta.6 修正的差異

| 項目 | 舊 Windows Lite | beta.6 |
|---|---|---|
| 自動散步 | 被 Windows 視窗動畫設定連帶停用 | App 專用開關預設開啟並保存選擇 |
| 動作安排 | 固定輪播與固定秒數 | 對齊 Mac 原生活動順序與 18–34 秒睡眠區間 |

| 提起、早放、再抓起、放下 | 已使用 Mac 時序與來源圖 | 保留並持續驗證 |

## 持續存在的平台差異

Windows 的 PNG 動作是離散取樣；Mac 可由原生繪圖函式連續計算。兩端不宣稱每一個時間點像素完全一致。Mac 的資料夾棲息／桌面物件跳躍、OS 閒置判斷、原生可及性整合尚未移植至 Windows Lite。Windows 自訂匯入圖片維持靜態，不宣稱具備九種內建花色的完整動畫。

## 驗證

Animation.Tests 核對來源時序向量、所有九色影格、提起／放下／中斷動作，並驗證固定距離不隨時間滑步、首次起步只使用一次、原生活動順序、實際行走距離與螢幕邊界。Windows smoke 另驗證真實計時器改變視窗位置，以及使用者暫停後位置維持不變。這些不替代實機的 DPI／多螢幕與原生輸入法驗收。
