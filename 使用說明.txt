What's up my neighbor — Windows 語音輸入測試版

開始：在右下角系統匣找到黑貓，先設定自己的 Groq API Key。
建立金鑰：https://console.groq.com/keys
請只在 App 的安全輸入欄貼上金鑰，不要傳給別人或寫進檔案。

點選要輸入的文字欄位，Ctrl + Alt + Space 開始錄音，再按一次完成。
小黑貓左眼取消，右眼完成。若辨識失敗保留錄音，右眼可重試。
App 只貼上，永不自動按 Enter；若無法確認輸入欄位，請 Ctrl + V 手動貼上。

從系統匣可以設定：快捷鍵、主語言／混用語言、純逐字／標準／簡潔、
數字轉換、麥克風、靜音停止、浮窗位置、登入啟動，以及詞典。
預設繁中＋英文、純逐字、靜音停止關閉、登入啟動關閉。
每段最多五分鐘，需要網路，錄音送至 Groq whisper-large-v3。

支援的輸入框中，修字穩定約 1.1 秒後顯示兩秒「不加入」。
未取消且仍能驗證時加入詞典。換焦點／無法讀取精確範圍時停止觀察。
不支援的 App 請在詞典中手動新增；這是提示詞學習，不是重新訓練模型。
整段選取並替換本次貼入的文字時，部分 App 會失去範圍邊界，此次學習將停止。
詞典最多 200 詞、每詞 40 字，提示長度有限，管理介面會顯示是否納入。

隱私：金鑰只存 Windows 認證管理員；不記錄私人轉錄或金鑰日誌。
設定與詞典：%LOCALAPPDATA%\WhatsUpMyNeighbor
錄音成功複製／取消／捨棄後刪除；失敗暫留兩分鐘供重試。
正常退出與下次啟動時清理殘留錄音。

遇到問題：
- 麥克風：確認 Windows 允許桌面應用程式使用麥克風。
- 貼上：保持原輸入框；權限較高程式或無法驗證的輸入框請手動貼上。
- 修字：詞典視窗有學習狀態；不支援範圍的 App 可手動新增。
- 短錄音仍可能出現無關文字，請核對結果；本版尚無完整幻覺防護。
- API 額度／服務錯誤不會觸發付費或其他供應商備援。

Windows 11 x64／Windows 10 22H2 x64；ARM64 未驗證。

設定、詞典與金鑰預設保留。完全清除時，先在 App 移除金鑰，再刪除個人資料夾。
