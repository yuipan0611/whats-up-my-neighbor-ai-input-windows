# Windows desktop walking artwork

Original SVGs copied unchanged from the user-provided macOS source archive,
`Resources/DesktopPet/`: sit, walk-body, walk-front-face, walk-foot-0 through 3.
Original project: https://github.com/yuipan0611/whats-up-my-neighbor-ai-input-macos
Copyright and MIT license remain in the repository LICENSE.

The first Windows walking implementation ports the diagonal paw offsets and
body-only reflection from `DesktopPetView.swift`. It does not implement pickup,
grooming, desktop icon perches, or the complete macOS state machine.
